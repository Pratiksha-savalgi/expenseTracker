# Expense Tracker

Simple personal expense tracker: **HTML/CSS/JS + Flask + SQLite**.

UI design: **B+C** (soft panels + compact table) — see `docs/design/chosen-design.md`.

## Setup

```bash
cd d:\expenseTracker
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000

## Features

- Register / login / logout
- Add, edit, delete expenses
- Filter by date range and category
- Filtered total + this month total
- Each user sees only their own data
